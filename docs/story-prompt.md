# ストーリー生成のプロンプト

子どもが出した種を、そのままパラグラフのグラフへ落とすための雛形。
下の全文をコピーし、`【ここに子どもが言ったこと】` を差し替えて LLM に渡す。

生成結果は `src/data/stories/` に置き、`npm test` を実行して検証を通すこと。
**検証に落ちたら直さずに生成し直す。** 人が直すより速い。

見本は `src/data/stories/area-5.json`。構造に迷ったらこれを読む。

---

## 使い方の順序

1. 子どもに聞く。**種は少なくてよい**
   - どんな場所で ぼうけんする？
   - どんな あいてが 出てくる？
   - なんて 名前？
2. 出てきた言葉をそのまま下の欄へ貼る。整えない
3. 生成された JSON を `src/data/stories/` に保存する
4. `npm test` で検証する。落ちたらエラーを添えて生成し直す
5. 中身を読む。子どもに見せたくない表現が無いか確認する

**LLM に話を考えさせない。** 種が無いまま生成した話は既製のドリルと同じ立場になり、
飽きるのも速い。種は敵の名前 1 つ、場所 1 行でも足りる。

---

## プロンプト本文（ここから下をコピー）

小学 2 年生向けの九九アプリに入れる、ゲームブック形式の短い冒険を JSON で作ってください。

### 子どもが言ったこと

```
【ここに子どもが言ったこと】
```

この内容を必ず話の中心に使ってください。あなたが新しく話を考えるのではなく、
上の言葉を話の形にするのがあなたの仕事です。

### 出力する JSON の形

```json
{
  "id": "area-5",
  "name": "エリアの なまえ",
  "stage": 5,
  "town": [
    { "progress": 0, "speaker": "だれか", "line": "..." },
    { "progress": 1, "speaker": "だれか", "line": "..." },
    { "progress": 2, "speaker": "だれか", "line": "..." },
    { "progress": 3, "speaker": "だれか", "line": "..." }
  ],
  "enemies": [
    {
      "id": "eng-id",
      "name": "あいての なまえ",
      "emoji": "🟢",
      "greeting": "たたかいの まえの ひとこと",
      "onCorrect": ["...", "...", "..."],
      "onWrong": ["...", "...", "..."]
    }
  ],
  "start": "p1",
  "paragraphs": [
    {
      "id": "p1",
      "text": "ばめんの せつめい",
      "battle": "eng-id",
      "outroWin": "かったときの むすび",
      "outroLose": "まけたときの むすび",
      "choices": [
        { "label": "えらぶ ことば", "to": "p2" },
        { "label": "えらぶ ことば", "to": "p3" }
      ]
    },
    { "id": "p7", "text": "さいごの ばめん", "end": true }
  ]
}
```

### 守ること

**文章**

- ひらがなとカタカナだけで書く。**漢字を使わない**
- 1 つの `text` は **100 字以内**。声に出して 30 秒で読める長さ
- 読点のかわりに 分かち書き（すきまを あける）を使う

**グラフの形**

- 街を出てから終端（`end: true`）まで、**どの経路も同じノード数**にする。**4 ノード**を目安にする
- 分岐は 2 か所。最後は 1 つの終端に合流させる
- `choices` の `to` は、必ず存在する `id` を指す
- `end: true` でないパラグラフには必ず `choices` を置く。**行き止まりを作らない**
- `end: true` のパラグラフに `choices` を置かない
- どこからもたどり着けないパラグラフを作らない

**戦い**

- **どの経路でも戦いの数を同じ**にする。**2 回**を目安にする
- `battle` のあるパラグラフには `outroWin` と `outroLose` を**両方必ず**書く
- **負けたときの話を、劣化版にしない。** 勝っても負けても話は前に進む。
  「ここで冒険は終わった」「最初からやり直し」は書かない

**あいての ことば**

- あいて自身も **かけざんを おぼえている最中**という立場で書く
- `onWrong` には必ず「自分も間違える」という趣旨を入れる。
  子どもを責める言い方をしない
- あいてごとに語彙を変える。同じ言い回しを別のあいてに使わない
- `onCorrect` と `onWrong` はそれぞれ 3 つずつ

**出さないもの**

- 「べんきょう」「ドリル」「がくしゅう」「テスト」という言葉
- 点数、ランク、れんぞく記録
- こわすぎる表現、暴力的な表現

### 出力

JSON だけを出力してください。説明文は不要です。
