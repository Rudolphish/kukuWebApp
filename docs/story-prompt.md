# ストーリー生成のプロンプト

子どもが出した種を、そのまま 1 エリアぶんのデータへ落とすための雛形。
下の全文をコピーし、`【ここに子どもが言ったこと】` を差し替えて LLM に渡す。

生成結果は `src/data/stories/` に置き、`npm test` を実行して検証を通すこと。
**検証に落ちたら直さずに生成し直す。** 人が直すより速い。

見本は `src/data/stories/area-1.json`（1 の段）と `area-5.json`（5 の段）。
構造に迷ったらこれを読む。

---

## 散策の形

エリアは「道」「場面」「出会い」の 3 つのプールでできている。
1 回の散策は必ずこの順で進む。

```
街 → 道をえらぶ → 場面 → 出会い(戦い) → 場面 → 出会い(戦い) → 街へ帰る
```

**骨組みは固定で、中身だけが毎回引き直される。**
場面を 1 つ足すだけで散策の組み合わせが増える。
経路そのものを枝分かれさせる形は採っていない。そちらは書いた本数ぶんしか遊べない。

---

## 使い方の順序

1. 子どもに聞く。**種は少なくてよい**
   - どんな ばしょで ぼうけん する？
   - どんな あいてが 出てくる？
   - なんて 名前？
2. 出てきた言葉をそのまま下の欄へ貼る。整えない
3. 生成された JSON を `src/data/stories/` に保存し、`src/lib/stories.ts` の `STORIES` に追加する
4. `npm test` で検証する。落ちたらエラーを添えて生成し直す
5. 中身を読む。子どもに見せたくない表現が無いか確認する

**LLM に話を考えさせない。** 種が無いまま生成した話は既製のドリルと同じ立場になり、
飽きるのも速い。種は あいての名前 1 つ、場所 1 行でも足りる。

## プロンプト本文（ここから下をコピー）

小学 2 年生向けの九九アプリに入れる、短い冒険のデータを JSON で作ってください。

### 子どもが言ったこと

```
【ここに子どもが言ったこと】
```

この内容を必ず話の中心に使ってください。あなたが新しく話を考えるのではなく、
上の言葉を話の形にするのがあなたの仕事です。

### 出力する JSON の形

```json
{
  "id": "area-3",
  "name": "エリアの なまえ",
  "origin": "original",
  "author": "つくった こどもの なまえ",
  "stage": 3,
  "town": [
    { "progress": 0, "speaker": "だれか", "line": "..." },
    { "progress": 1, "speaker": "だれか", "line": "..." },
    { "progress": 2, "speaker": "だれか", "line": "..." },
    { "progress": 3, "speaker": "だれか", "line": "..." }
  ],
  "forkText": "みちが ふたつに わかれている。",
  "branches": [
    { "id": "left", "label": "ひだりの みちへ" },
    { "id": "right", "label": "みぎの みちへ" }
  ],
  "enemies": [
    {
      "id": "eng-id",
      "name": "あいての なまえ",
      "emoji": "🟢",
      "greeting": "たたかいの まえの ひとこと",
      "onCorrect": ["...", "...", "..."],
      "onWrong": ["...", "...", "..."]
    }
  ],
  "scenes": [
    { "id": "s-1", "text": "なにも おきない ばめんの せつめい" }
  ],
  "encounters": [
    {
      "id": "e-1",
      "branch": "left",
      "enemy": "eng-id",
      "text": "あいてと であう ばめん",
      "outroWin": "かったときの むすび",
      "outroLose": "まけたときの むすび"
    }
  ]
}
```

### 数の決まり

| 項目 | 数 |
| --- | --- |
| `branches`（道） | ちょうど 2 つ |
| `scenes`（場面） | 6 つ以上 |
| `enemies`（あいて） | 8 体（道ごとに 4 体ずつ） |
| `encounters`（出会い） | 8 つ。**道ごとに 4 つずつ**。あいて 1 体につき 1 つ |
| `town`（街のセリフ） | progress 0 から 3 の 4 つ |

道ごとに出会いが 4 つ必要なのは、1 回の散策で 2 つ引き、
次の散策では直近に出たものを避けるため。3 つ以下だと毎回同じ顔ぶれになる。

### 守ること

**文章**

- ひらがなとカタカナだけで書く。**漢字を使わない**
- 1 つの文は **100 字以内**。声に出して 30 秒で読める長さ
- 読点のかわりに 分かち書き（すきまを あける）を使う

**出会い**

- `outroWin` と `outroLose` を**両方必ず**書く
- **負けたときの話を、劣化版にしない。** 勝っても負けても話は前に進む。
  「ここで冒険は終わった」「最初からやり直し」は書かない
- `encounter` の `branch` は必ず `branches` のどれかを指す
- `encounter` の `enemy` は必ず `enemies` のどれかを指す

**あいての ことば**

- あいて自身も **かけざんを おぼえている最中**という立場で書く
- `onWrong` には必ず「自分も間違える」という趣旨を入れる。
  子どもを責める言い方をしない
- あいてごとに語彙を変える。同じ言い回しを別のあいてに使わない
- `onCorrect` と `onWrong` はそれぞれ 3 つずつ

**道**

- 2 つの道で、出会う あいて の雰囲気を変える
  （例: 明るい場所と暗い場所、空と水辺）。選ぶ意味が出る

**出さないもの**

- 「べんきょう」「ドリル」「がくしゅう」「テスト」という言葉
- 点数、ランク、れんぞく記録
- こわすぎる表現、暴力的な表現

### 出力

JSON だけを出力してください。説明文は不要です。
